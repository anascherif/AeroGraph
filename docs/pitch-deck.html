The challenge

For a sighted person, walking into a room tells you everything: where the furniture is, what changed since yesterday, where you left your keys.

For a blind or low-vision person, every visit is a fresh scan. There is no “memory of space.” Objects move. Hazards appear. The environment changes silently.

Architecture

How it works

Body-worn camera + on-device spatial graph + voice interface = a continuous photographic memory of the user's environment.

01

Detect

YOLO11n ONNX pipeline detects 49 COCO classes at 5 FPS. Runs entirely on CPU — no GPU needed. Body-worn camera, user never in frame.

02

Graph

Spatial encoding into a vector store. Objects, locations, and timestamps indexed across 60+ sessions. Environment changes tracked per visit.

03

Query

Voice RAG via NVIDIA NIM (Groq STT fallback). Natural-language queries: “Where did I leave the blue bottle?” returns spatial answers.

04

Respond

SAPI5 TTS pinned to English voice. If user doesn't respond to safety prompt within 30s, family contacts escalate via Telegram + WhatsApp.

$0 budget · CPU-only · 11th Gen Intel i7

Safety subsystem

Safety monitor — distress detection

Monitoring

3 orthogonal signals: motion energy, vertical tilt (Farneback), brightness EMA drop — fused with 2/3 majority for ≥8s

→

Confirming

30s voice prompt: “Are you okay? Say I'm okay.” TTS repeats every 10s. Was-moving-within-60s guard prevents false alarms.

→

Escalating

Multi-channel alert: Telegram (text + voice note), WhatsApp, and optional Twilio call. State machine tracks delivery.

→

Cooldown

60s pause before re-arming. Prevents re-trigger loops. Full state lock with per-worker watchdog.
